# Research roadmap

## Track A: Product-ready MVP

- Stabilize iPhone capture loop
- Verify ROI upload quality on real homework pages
- Add robust error handling and user-visible status
- Build and upload a signed TestFlight build

## Track B: Low-latency tutoring loop

- Replace local Apple Speech with OpenAI Realtime
- Add VAD and interruption handling
- Add turn-taking and streaming coach responses

## Track C: Better process guidance

- Add temporal memory with event windows
- Add local OCR on edge node
- Detect hesitation, repeated regressions, and attention drops
- Use a teaching strategy tree instead of a single generic prompt

## Track D: Gaze and focus precision

- Calibrate page corners
- Estimate page pose
- Project the front-camera gaze proxy into page coordinates
- Compare the approximate and calibrated ROI hit rates
